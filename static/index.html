🛡️ ApprovalGuard

Wallet-approval security scanner agent. Paste any EVM address — it scans ERC20 token approvals from public on-chain data (no keys, no sign-in) and returns a signed risk report.

Try the prefilled address (vitalik.eth), or any address you own. Quick scans check recent history; full scans walk the whole outgoing-transaction history. A full scan of a busy address can take a couple of minutes.

How it works

  • Discovery: outgoing transactions are scanned for approve() calls (full history), plus a recent-window eth_getLogs scan for permit-based approvals.
  • Verification: every discovered approval's current allowance is read on-chain, and each spender is checked for contract code.
  • Risk flags: unlimited allowances, externally owned spenders, unknown spenders, stale approvals, and allowances exceeding the current balance.
  • Signed reports: every report is signed with the agent's Ed25519 key. Verify any report below or via POST /verify.

API

GET  /health                      liveness + agent public key
GET  /scan?address=0x...&depth=quick
POST /scan                        {"address": "0x...", "chain": "ethereum", "depth": "full"}
POST /agent                       Agent Games task envelope (HMAC-aware)
POST /verify                      {"report": {...signed report...}} → {"valid": true/false}
GET  /example                     a real signed example report

Verify a report

Paste a full signed report JSON (from a scan above or /example) and check its signature.

ApprovalGuard is read-only. It never asks for a seed phrase, private key, or signature, and it cannot revoke anything. Built for the Agent Games Wildcard track. Source and docs: see the project README.
